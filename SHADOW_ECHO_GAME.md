# 🎮 Shadow Echo: The Memory Thief

## 🌍 Genre

Adventure + Psychological Puzzle + Action + Multiplayer Strategy

## 🎯 Game Concept

In this game, players don't steal money or weapons — they steal memories.

Every player has a "memory core." Your abilities depend on the memories you collect. If someone steals your memory, you forget skills temporarily.

---

## 🧠 Core Unique Idea

Instead of a health bar, players have:

- 🔵 **Memory Points (MP)**
- 🟣 **Identity Stability (IS)**

If Identity Stability reaches zero, your character forgets who they are and becomes controlled by AI temporarily.

---

## 🌆 Game World

The world is divided into 3 zones:

| Zone | Description |
|------|-------------|
| **Reality City** | Normal world (safe zone) — Cyberpunk look |
| **Echo Realm** | Dream-like world where memory battles happen — Floating buildings, broken sky |
| **Void Zone** | Dangerous zone where lost memories are trapped — Black & neon purple environment |

Players travel between these zones during gameplay.

---

## ⚔️ Gameplay Mechanics

### 1. Memory Stealing System

When you defeat a player, you can:

- Steal a skill memory
- Steal a movement ability
- Steal emotional traits (e.g., anger = more attack power)

**Examples:**
- Steal "Bravery Memory" → you become stronger
- Someone steals your "Speed Memory" → you move slower

### 2. Emotional Power System

Emotions dynamically change gameplay:

| Emotion | Effect |
|---------|--------|
| Fear | Faster escape speed |
| Anger | Stronger attack power |
| Calmness | Better defense |
| Curiosity | Unlock hidden paths |

### 3. Memory Crafting

Players can combine memories to create new abilities:

| Combination | Result |
|-------------|--------|
| Fire Memory + Rage Memory | Explosive Attack Skill |
| Stealth Memory + Calmness | Invisibility Mode |

---

## 👥 Multiplayer Mode

### 🎭 Identity Swap Mode

You can temporarily enter another player's mind and control their character for 10 seconds.

This creates:
- Betrayal
- Confusion
- Strategic opportunities

---

## 🎮 Game Modes

1. **Story Mode** — Single player psychological story
2. **Online Battle Mode** — Competitive memory stealing
3. **Memory Hunt** — Treasure hunt style exploration
4. **Team Identity War** — Team-based strategy

---

## 🏆 Level System

Instead of traditional leveling, you progress by:

- Discovering hidden memories
- Solving emotional puzzles
- Winning mind battles
